# 食生活の異常検知

## 扱うこと

食事の記録から、食生活の異常をどう検知するか

## 答え方と理由

### 0. 判断全体

日は、【日付の境界】で区切る。境界の時刻より前の記録は、前日の記録として数える。記録日は、この区切りで数えて、食事・間食の記録が1件以上ある日とする。

記録が間食かどうかは、`間食の表現`（例：「おやつ」「デザート」「間食」「スイーツ」）が記録にあるかで判断し、それ以外を食事とする。

### 1. 食事の回数が上限を超えた日を、異常とする

その日の食事の回数が、【食事の回数の上限】を超えたら異常とする。時間帯が重なる記録は、1回と数える。

1. 記録なし

### 2. 間食の回数が上限を超えた日を、異常とする

その日の間食の回数が、【間食の回数の上限】を超えたら異常とする。

1. 記録なし

### 3. 過食の表現がある記録を、検出する

記録に `過食の表現`（強調表現・内省表現）があれば、その記録を検出する。

1. 記録なし

### 4. 外食の回数が7日間で上限以上なら、異常とする

記録が外食かどうかは、`外食の表現`（例：「@ 店名」「at 店名」「会食」「飲み会」「ランチ」）が記録にあるかで判断する。`外食を否定する表現`（例：「中食」「内食」）があれば、`外食の表現` があっても外食にしない。最新の記録日から遡る7日間ごとに外食の回数を数え、【異常とする外食の回数】以上なら異常とする。

1. 記録なし

### 5. 記録が1回も無い日を、記録不足として検出する

食事・間食の記録が1回も無い日は、「食べていない」と読まず、記録不足の日として検出する。数えるのは、渡された記録の最初の記録日から最新の記録日までの日だけ。

1. 記録なし

### 6. 間食の回数が7日間で上限以上なら、異常とする

最新の記録日から遡る7日間ごとに間食の回数を数え、【異常とする間食の回数】以上なら、間食が多かった週として異常とする。間食かどうかは「0. 判断全体」と同じく見分け、1日の上限（答え方2）に当たらない日の間食も数える。

1. 記録なし

### 7. 期間の食事を、外食・中食・内食に分けて数える

渡された記録の最初の記録日から最新の記録日までと、最新の記録日から遡る7日間ごとに、食事（間食を除き、時間帯が重なる記録を1回にしたもの）を数え、外食・中食・内食の食事に分けて数える。外食かどうかは答え方4と同じく見分ける。外食でない食事は、記録に `中食の表現` があれば中食、`内食の表現` があれば内食、どちらも無ければ印の無い食事とする。時間帯が重なって1回にした食事は、外食・中食・内食の順に、どれかの記録が当たった入手元にする。

1. （根拠）作成者が、期間の食事のうち外食がどれだけあるかを見たいとし、間食を除いた食事を全体にすると決めた。（決定日：2026-11-21）
2. （根拠）作成者が、7日間ごとの食事の回数を、内食・外食・中食に分けて見たいとした。（決定日：2026-11-21）

## 求める材料

| 材料 | 種類 | 必須 | 形 | 無いとき |
|---|---|---|---|---|
| `食事` | 対象の値 | ○ | `[{"日付": "2026-10-05", "時刻": "12:00", "終了": "12:30", "記録": "食事(@ 店名, ラーメン大盛)"}]` | 判断できない |
| `間食の表現` | 取り決め | | `["おやつ", "デザート", "間食", "スイーツ"]`。間食の記録に書かれる表現 | 食事と間食を見分けられないので、答え方1・2・6・7を見ず、その旨を伝える |
| `過食の表現` | 取り決め | | `["大盛", "食べ放題", "食べ過ぎた", ...]`。過食の記録に書かれる強調表現・内省表現 | 答え方3を見ず、その旨を伝える |
| `外食の表現` | 取り決め | | `["@ ", "at ", "会食", "飲み会", "ランチ"]`。外食の記録に書かれる表現 | 答え方4・7を見ず、その旨を伝える |
| `外食を否定する表現` | 取り決め | | `["中食", "内食"]`。外食ではない記録に書かれる表現 | 否定の表現を使わずに外食を見分け、その旨を伝える |
| `中食の表現` | 取り決め | | `["中食"]`。買ってきたものを食べた記録に書かれる表現 | 答え方7で中食を数えず、その旨を伝える |
| `内食の表現` | 取り決め | | `["内食"]`。家で作って食べた記録に書かれる表現 | 答え方7で内食を数えず、その旨を伝える |

## 計算

`judge.py meal-pattern` が、答え方1〜3のどれかに当たる日ごとに、食事・間食と、食事の回数の異常・間食の回数の異常・過食の表現がある記録を返す。あわせて、`外食` と `間食` に7日間ごとの回数と異常かを、`外食` の `期間の合計` に期間と7日間ごとの食事の回数と、外食・中食・内食・印の無い食事の回数（答え方7）を、`記録不足の日` に記録が1回も無い日を返す。
